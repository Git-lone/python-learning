## HTTP 可靠性是什么

调用远程服务时，网络可能超时、连接失败、返回错误状态或返回结构不合合同的数据。可靠性不是简单地“多试几次”，而是先定义单次超时、总体截止时间、允许重试的错误、最大尝试次数和副作用语义。`retries=1` 一般表示首试之外再试一次。

## 组成与使用场景

本章用 Python 标准库 HTTP 服务和客户端演示基本边界；真实项目还可能使用项目已锁定的 HTTP 客户端或模型 SDK。远程模型、Embedding、搜索和内部微服务都遵守类似原则。只有暂时性错误适合有限重试；对支付、发布等写操作，必须先有幂等机制。

响应状态 200 只能说明 HTTP 层收到了成功响应，不能证明数据合法。还要检查媒体类型、JSON 根类型、字段类型和值域。把错误在边界映射为清楚的异常，业务层就不必猜测网络细节。
