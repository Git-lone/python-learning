# 第 16 章学案：检索证据与对话记忆

配合[本章讲解](README.md)使用，分别画出检索和记忆两条数据路径。

## RAG 与记忆是什么

RAG（检索增强生成）先从外部资料找到与问题相关的片段，再把片段连同问题交给生成模型；它改善模型利用当前资料的能力，不会重新训练模型。对话记忆则管理过去交互中哪些信息要保留：短期窗口、摘要或外部事实存储。两者都可能把不可信或过期信息送进模型，因此需要来源、权限和更新策略。

## 技术组成与落地场景

完整检索链通常包括文档读取、切块、索引、查询、召回、重排、引用和回答；可选词法索引或 Embedding/向量索引。本章只实现词项重叠的离线基线和有界对话窗口，第 22 章再引入 BM25 与评测。内部知识问答、客服政策查询、代码库助手都适用；固定规则判定则通常不需要 RAG。

访问控制应在检索候选时执行，不能只靠提示词要求模型忽略无权文档。零分或无相关证据时应拒答；生成答案还需要检查引用是否真的支持结论。记忆写入是副作用，要规定保存范围、保留期和删除方式。
