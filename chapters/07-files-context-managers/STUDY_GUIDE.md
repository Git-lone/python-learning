# 第 7 章学案：文件与资源生命周期

配合[本章讲解](README.md)使用，重点观察异常路径中的资源释放。

## 文件和上下文管理是什么

文件操作有获取、使用、释放三个阶段。`with` 让资源对象在进入代码块时准备，在离开时执行清理；即使块内抛异常也会调用退出逻辑。它对应 Java 的 try-with-resources，但 Python 还把同样机制用于锁、数据库连接和临时目录。

## 组成与使用场景

本章使用标准库 `pathlib.Path`、文件对象、JSON 和临时目录。适合读取配置、处理日志、导入数据与生成报告。数据量大时逐行读取，避免 `read_text()` 或 `readlines()` 无条件把全部内容装进内存。文本编码应显式指定，避免不同系统的默认编码造成乱码。

“文件不存在”与“文件存在但没有非空行”是两个不同结果。前者应保留错误，后者可返回 0；把两者都返回 0 会让调用方误以为已经完成读取。

## 代码怎样工作

[示例](examples/ch07_files.py)先在临时目录中写 JSON，再打开文件读取；文件 `with` 和临时目录 `with` 各自管理一层清理。[练习](exercises/exercise_ch07.py)应在文件上下文里逐行判断 `line.strip()`，累加非空行，退出时由上下文管理器关闭文件。
