# 第 12 章学案：配置解析与安全日志

配合[本章讲解](README.md)使用，把外部字符串在入口处转换成明确类型。

## 配置、CLI 和日志是什么

配置决定程序在不同环境如何运行；CLI 把命令行参数变成结构化输入；日志记录运行事件以便排障。环境变量和命令行传入的都是外部字符串，必须在应用入口转换、校验和决定优先级。库模块只处理已校验的配置对象，不应重新解析同一端口字符串。

## 组成与使用场景

本章用 `os.environ` 或可注入映射、参数解析、数据类和 `logging` 标准库。适合批处理、Web 服务和 Agent 进程配置。配置优先级常按明确规则处理，例如命令行覆盖环境变量，再退回默认值；具体优先级应写进项目合同。密钥不能硬编码或写入日志。

日志应记录事件名称、请求 ID、级别和稳定错误码。完整提示词、用户隐私和访问令牌通常不应默认落盘；追踪 Agent 时尤其要区分“可审计元数据”和“敏感正文”。

## 代码怎样工作

[示例](examples/ch12_configuration.py)用固定环境映射代替真实机器配置，把日志写到内存流，因此运行和测试可复现。[练习](exercises/exercise_ch12.py)先把字符串端口转换为整数并检查 `1..65535`，再严格解析布尔值；`bool('false')` 为真，不能用来实现配置解析。
