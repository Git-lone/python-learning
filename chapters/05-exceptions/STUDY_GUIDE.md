# 第 5 章学案：异常与错误翻译

配合[本章讲解](README.md)使用，分别记录格式错误和业务规则错误。

## 异常是什么

异常把无法按正常路径完成的情况从返回值中分离。Python 的 `try` 尝试操作，`except` 处理预期错误，`else` 只在没有异常时执行，`finally` 用于无论结果如何都要执行的清理。`raise DomainError(...) from error` 会保留原始错误链，类似 Java 包装异常时传入 cause。

## 组成与使用场景

本章只用语言内建异常机制。解析用户输入、访问文件、调用外部 API 时，底层错误常需要转成稳定的业务错误；程序 bug 和可恢复的用户错误则不应全部混成同一种异常。已有上下文管理器的资源，优先用 `with` 管理生命周期。

例如用户输入 `"abc"` 无法转换为数量，是格式错误；输入 `"0"` 可以转换，但违反“数量至少为 1”的业务规则。两者可以对外呈现统一的 `InvalidQuantityError`，内部的原因链却不同。
