# 第 3 章学案：闭包与装饰器

配合[本章讲解](README.md)使用，重点追踪函数创建与调用发生在不同时间。

## 函数、闭包和装饰器是什么

Python 函数是对象，可以赋给名称、作为参数传递，也可以作为返回值。闭包是返回的函数继续使用外层函数局部变量的一种方式；装饰器接收函数、返回替代函数，常用于记录调用、校验或缓存。它们与 Java 的策略对象、函数式接口和 AOP 有相似用途，但包装过程在 Python 中更直接。

## 组成与使用场景

技术组成是 `def`、参数机制、词法作用域、`functools.wraps`，以及在需要静态类型时的 `ParamSpec`/`TypeVar`。例如订单折扣策略可由工厂捕获折扣率；调用跟踪可由装饰器包住函数。若每次都要改写复杂业务逻辑，优先抽取普通函数或对象，避免堆叠难排查的装饰器。

默认参数在定义函数时求值。`def add(item, items=[])` 的列表会在多次调用之间共享；用 `None` 占位并在函数内新建列表，才能保证每次独立。

## 代码怎样工作

[示例](examples/ch03_functions.py)创建闭包后，外层调用虽然结束，返回函数仍能访问已捕获状态；装饰器先保存原函数，再由包装函数执行前后逻辑。`@wraps` 保留原函数元数据。[练习](exercises/exercise_ch03.py)要求在工厂创建时验证折扣率，之后每次调用只处理价格；要区分这两个时间点。
