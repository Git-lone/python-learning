## 1. 蚂蚁 Agent 开发一面

- 原帖：[蚂蚁agent开发一面面经分享](https://www.nowcoder.com/feed/main/detail/7a0ddb8e077041d4b72ba9e5290ad36a)
- 作者：牛肉葱油饼。页面时间：04-24 05:40，年份未显示；具体面试日未注明。
- 公司与轮次：标题自述为蚂蚁 Agent 开发一面，正文提到 Agent 实习项目；不能据此确认应聘类型。

**原帖问题摘要（转述）：** 单/多 Agent 如何选择，角色之间如何通信，并发访问数据库或文件如何协调；还涉及混合检索、幻觉、MCP、上下文管理、工具失败和上线质量保障。

**本教程补充，不是面试官原话：** 先用[第 17 章](../chapters/17-ai-agent-engineering/README.md)解释决策循环，再用[第 21 章](../chapters/21-durable-workflow/README.md)说明为什么断点恢复还需要业务幂等。能拿出一条失败请求的完整过程，比只列框架名更有说服力。

**练习：** 两个执行者同时提交同一个请求，证明最终只有一条记录；再把相同幂等键的载荷改掉，证明系统拒绝冲突。

## 2. 未公开名称公司的 AI Agent 应用开发一面

- 原帖：[AI agent应用开发一面面经](https://www.nowcoder.com/feed/main/detail/416c3118a9c84fe0a43dc00f9eb9bec2)
- 作者：java 选手面试前背框架。页面时间：03-03 10:31，年份未显示；具体面试日未单独注明。
- 背景：作者自述面试一家游戏类公司，项目是口腔医疗领域多模态、多 Agent 系统；这不是推荐把医疗决策交给无人监督 Agent。

**原帖问题摘要（转述）：** 项目节点如何设计、实现过哪些 MCP 工具、上下文与记忆怎么处理；现场设计可反馈迭代的 AI 漫剧流程，说明关键困难、人物一致性、片段评估与首版取舍。

**本教程补充，不是面试官原话：** 用“目标与禁止事项 -> 最小流程 -> 输入输出合同 -> 质量检查 -> 人工介入 -> 成本预算”的顺序设计。场景可以换，但不要不问边界就堆多 Agent。

**练习：** 结合[第 20 章](../chapters/20-mcp-protocol/README.md)写工具 schema，再按[系统设计题](INTERVIEW_PRACTICE.md)完成 15 分钟的客服草稿助手设计。多模态生成未在当前代码中实现，不能以运行本项目代替这部分实践。

## 3. 未公开名称公司的 Agent 岗位复盘

- 原帖：[面完一家Agent岗位，整个过程记录一下（有些地方答得挺拉的，诚实交代）](https://www.nowcoder.com/discuss/916713177822298112)

- 公司匿名；作者发帖时称仍在等待结果。

**原帖问题摘要（转述）：** Agent 与 Chatbot 的边界；为什么用 LangGraph；不用框架时怎样写最小循环；设计客服工单 Agent 时先定义问题与自动化边界，而不是先列组件。

**本教程补充，不是原帖标准答案：** 不要机械地断言“工具只调用一次就不算 Agent”。应讨论谁决定下一步、状态和反馈如何影响行为、系统授予多少自主权；一次任务恰好只需一个动作，并不能单独决定系统类别。

**练习：** 不看代码口述[第 17 章](../chapters/17-ai-agent-engineering/README.md)的终止条件；再解释[第 21 章](../chapters/21-durable-workflow/README.md)引入框架具体省掉哪些工作，以及一个简单定时查询为什么未必需要框架。

## 怎么使用这些面经

1. 先读问题摘要，在没有参考答案的情况下说 2 分钟。
2. 打开对应章节，运行一条成功用例和一条失败用例。
3. 录下自己的回答，用[练习评分表](INTERVIEW_PRACTICE.md)检查定义、实现细节、取舍、证据和边界。
4. 每次应聘复盘新增“实际被问的问题、当时回答、暴露缺口、补充实验”，并区分自己亲历与转载来源。

这些样本包含实习岗位，不代表社招考察深度。对有 Java 经验的候选人，应额外准备服务稳定性、数据一致性、权限、成本和故障排查的真实经历。不得将他人的项目、指标或面试经历写成自己的。
