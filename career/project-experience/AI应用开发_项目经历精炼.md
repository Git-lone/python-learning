# AI 应用开发：近期项目经历精炼版

面向五年 Java 开发经验、求职 AI 应用开发的项目摘录。每项只保留可展开讲解的技术难点；投递时优先选前三项，偏自动化执行的岗位可将第四项替换进去。

交给其他 AI 继续加工时，使用[完整功能实现与项目经历详解](AI应用项目_实现机制与项目经历详解.md)，其中展开原项目的架构、完整流程、状态和异常恢复，不依赖源码访问。

## 1. 企业业务 Agent：工具开发与可靠执行

**技术：** Java、Spring AI、Spring Cloud、MySQL、Redis。

- **业务 Tool 与参数契约：** 开发英国 VAT 业务工具，对接账户校验、资料复用及税务办理接口；将模型输入、服务端身份和固定业务参数分开处理，同步维护工具签名、元数据、Feign 适配及契约测试，约束模型可传参数，解决工具描述与实际接口不一致的问题。
- **确认、执行与结果一致性：** 参与工单执行链路建设，以确认快照绑定执行内容，将请求领取、工单保存和成功状态更新放入业务服务的同一事务；跨服务超时后查询权威结果，无法确认时保留未知状态，并分离通知与落单结果，避免通知失败触发重复创建。

## 2. 税务资料 AI：模型输出治理与异步回填

**技术：** Java、DeepSeek、Dify、RocketMQ、MySQL、Redis、Vue。

- **模型故障与业务数据隔离：** 在本人负责的企业资料采集链路中接入 DeepSeek 地址国家识别，校验输出结构、业务 ID 和国家白名单，拒绝歧义结果；将模型推理与付费查询结果保存解耦，超时或执行队列拒绝时保留已取得资料，通过异步补偿继续识别，最终匹配与写入仍由业务规则控制。
- **长任务与迟到结果治理：** 参与资料 AI 助手建设，以交互标识、任务状态和 CAS 控制执行及结果写回，隔离取消、超时和旧会话结果；区分模型建议、用户确认与实际表单赋值，结合 Dify 输出契约和页面字段规则完成已验证场景的 UAT 回填联调。

## 3. 多国专利图像检索：联合召回与结果编排

**技术：** Java、Milvus、Elasticsearch、Redis。

- **跨国向量召回：** 负责向量服务接入与检索 API，完成 7 个国家或地区的策略适配，将逐国向量查询合并为一次联合召回；分开处理图片向量提取与相似检索，分别校验向量维度及调用超时。
- **异构结果与分页复用：** 按“国家＋检索标识”去重，批量补全 Elasticsearch 详情后恢复向量命中顺序，解决跨国同号及结果乱序问题；分离检索快照与页级额度计次，同一次检索的后续分页复用已有召回结果，并按商户隔离缓存。

## 4. 配置驱动 RPA：执行能力扩展与副作用治理

**技术：** Java、Selenium WebDriver、HtmlUnit、Playwright、Redis。

- **共享节点与动态文件获取：** 扩展既有 RPA 引擎的原生输入、显式等待及 Blob PDF 解析能力，解决受控表单“页面有值但框架状态未更新”、动态文件没有稳定下载地址的问题，将页面交互与文件获取沉淀为可复用节点能力。
- **提交成功后的恢复边界：** 修复外部申请已成功却因附件下载失败导致整项重提的问题，将已确认的业务提交与后置归档分开判定；结合执行批次和当前业务节点复核处理重试及迟到回调，避免旧任务结果干扰新执行。
